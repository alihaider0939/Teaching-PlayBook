# ⚡ Peer-Level AI Teaching Hacks

> Daily micro-hacks, visual anchors, and ChatGPT prompts to help teachers explain complex concepts like a smart classmate the night before an exam.

---

## 💡 What Is This Project?

Traditional teaching relies on dense textbooks and rote memorization. Today's students learn through visual clarity, system shortcuts, and peer-to-peer mental models. 

This repository provides **daily, high-impact teaching hacks** paired with ready-to-use AI prompts to help educators modernize their classrooms instantly.

---

## 📌 Repository Structure

* **`daily_hacks/`** — Daily 2-minute micro-lessons featuring a shortcut, a peer analogy, and an AI prompt generator.
  * `day_01_the_multiply_by_5_trick.md` — Scale Up, Cut Down math hack.
* **`01_understanding_genz_learners.md`** — The core framework comparing traditional vs. Gen Z mental models.
* **`02_peer_level_teaching_hacks.md`** — Master prompt templates for dates, memory anchors, and math tricks.

---

## 🚀 How to Use

1. **Pick a Hack:** Browse the `daily_hacks/` folder for your subject.
2. **Copy the Prompt:** Paste the ready-to-use ChatGPT/Gemini prompt to generate customized worksheets or scripts.
3. **Teach Like a Peer:** Skip the textbook jargon and explain concepts using visual anchors and shortcuts.
